# هدهد Level MAX — دمج واجهات الأدوار

## الملفات
- `index.html`: نسخة مدمجة من صفحة المرحلة الأولى، مع تبويب «مساحة الحساب».
- `web/classrooms.js`: واجهة اتصال المرحلة الثانية.
- `web/role-dashboard.js` و`web/role-dashboard.css`: واجهات المدير والمعلم والطالب.

## مسار الاستخدام
1. افتح تبويب «مساحة الحساب» وسجّل الدخول.
2. يتم التحقق من `role` من Firebase ID Token Claims (`admin`, `teacher`, `student`).
3. المعلم ينشئ صفاً ويشارك رمز الانضمام.
4. الطالب يرسل الرمز وينتظر الموافقة.
5. المعلم يختار الصف من «طلبات الانضمام» ثم يقبل أو يرفض.
6. المدير يستطيع عرض الصفوف وإيقافها أو تفعيلها.

## حدود هذه النسخة
- لا يوجد نشر إلى Firebase أو GitHub.
- لم يتم اختبار الاتصال بمشروع Firebase أو Emulator.
- يلزم نشر وظائف المرحلة الثانية وقواعد RTDB ومراجعتها قبل استخدام الميزات السحابية.
- لا ترفع مجلد `functions` أو مفاتيح Admin SDK إلى GitHub Pages.
- احتفظ بنسخة من `index.html` الحالي قبل استبداله.
